# PCT Shift Sheets

Printable one-page worksheets that Patient Care Technicians use to organize
a shift: vitals and glucose times, baths, linens, and general notes.

Live page: https://bradene0.github.io/pct

## What is hosted here

| File         | Purpose                                   |
|--------------|-------------------------------------------|
| `index.html` | Landing page with links to the two sheets |
| `day.pdf`    | Day shift sheet (0700 / 1100 / 1500)      |
| `night.pdf`  | Night shift sheet (1900 / 2300 / 0300)    |

## Security and privacy

- **No patient data.** The PDFs are blank templates. Nothing is entered,
  uploaded, or stored through this site.
- **Static files only.** No forms, logins, databases, or server-side code.
- **No scripts, cookies, analytics, or third-party embeds** in the page itself.
- **Hosting.** Served over HTTPS by GitHub Pages. As with any web host,
  GitHub may log visitor IP addresses per its own privacy policy.
- **Source is public.** Every file served is visible in this repository.

## Use of printed sheets

Once filled in by hand, a sheet contains patient information and should be
handled and disposed of according to facility policy (shred bin at end of
shift).
